## Interaction Patterns

1. **Location-First Flow:**
   - Auto-detect location → Manual entry → Address selection

2. **Authentication Gate:**
   - WhatsApp OAuth → Phone OTP → Session creation

3. **Subscription Purchase:**
   - Browse → Compare → Add to Wallet → Checkout → Confirmation

4. **Group Sharing:**
   - Discover → Join → Share → Manage → Access

5. **Support Flow:**
   - Chat tab → Message support → Real-time response → Resolution
